# hospitality-rag

A RAG (Retrieval-Augmented Generation) system that answers questions about Indian
hospitality compliance — FSSAI licensing, state hotel licensing, GST for
hospitality — using only official documents, with citations back to source.

Status: early scaffolding, learning project. No retrieval or generation logic yet.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
